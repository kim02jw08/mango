# 하늘 여행 계획사이트 🌤️✈️

원하는 국가와 여행 일수를 입력하면 완벽한 여행 계획을 자동으로 생성해주는 웹사이트입니다.

## ✨ 주요 기능

- **국가별 여행 계획**: 15개 국가의 상세한 여행 정보 제공
- **맛집 추천**: Google Maps API를 활용한 실제 맛집 정보
- **관광지 안내**: 자연 명소, 문화재, 테마파크 등 다양한 볼거리
- **숙소 추천**: 다양한 가격대의 숙소 옵션
- **예산 계산**: 숙박비, 식비, 교통비, 활동비를 포함한 총 예산 산출
- **하늘 테마 UI**: 비행기 창문에서 바라보는 구름 가득한 하늘 테마

## 🚀 사용법

1. 웹사이트에 접속
2. 여행하고 싶은 국가 선택
3. 여행 일수 입력 (1-30일)
4. "여행 계획 생성하기" 버튼 클릭
5. 자동으로 생성된 상세한 여행 계획 확인

## 🌍 지원 국가

- **아시아**: 일본, 한국, 태국, 베트남, 싱가포르
- **유럽**: 프랑스, 이탈리아, 스페인, 독일, 영국
- **아메리카**: 미국, 캐나다
- **오세아니아**: 호주, 뉴질랜드

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **API**: Google Maps Places API
- **UI/UX**: 반응형 디자인, CSS 애니메이션
- **이미지**: Unsplash API

## 🔧 설치 및 실행

1. 프로젝트 파일 다운로드
2. `index.html` 파일을 웹브라우저에서 열기
3. Google Maps API 키 설정 (선택사항)

### Google Maps API 설정 (선택사항)

더 정확한 맛집과 관광지 정보를 위해 Google Maps API를 사용할 수 있습니다:

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트 생성
2. Places API 활성화
3. API 키 생성
4. `index.html`과 `script.js`에서 `YOUR_API_KEY`를 실제 API 키로 교체

## 💰 예산 계산 기준

각 국가별로 다음과 같은 일일 예산 기준을 적용합니다:

- **숙박비**: 호텔/게스트하우스 가격
- **식비**: 현지 음식 비용
- **교통비**: 대중교통, 택시 비용
- **활동비**: 입장료, 체험비용

## 🎨 디자인 특징

- **하늘 테마**: 구름이 떠다니는 애니메이션 배경
- **그라데이션**: 하늘색 계열의 아름다운 그라데이션
- **반응형**: 모바일, 태블릿, 데스크톱 모든 기기 지원
- **애니메이션**: 부드러운 CSS 애니메이션 효과

## 📱 반응형 디자인

- **태블릿**: 768px - 1199px
- **모바일**: 767px 이하
